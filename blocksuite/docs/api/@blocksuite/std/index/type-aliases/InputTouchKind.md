# Type Alias: InputTouchKind

> **InputTouchKind** = `"pencil"` \| `"finger"` \| `"palm"`

Pointer input classification returned by `classifyPointerInput()`.

`"pencil"` represents Apple Pencil input, `"finger"` represents deliberate touch
input, and `"palm"` represents touch contact that pointer routing should reject.
