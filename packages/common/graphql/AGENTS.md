# @affine/graphql

Auto-generated GraphQL client for AFFiNE. Contains two layers: the **generated artifacts** (TypeScript types + typed operation objects, produced from `.gql` files and the server schema) and the **fetcher** (a typed, file-upload-aware `fetch` wrapper). Do not edit generated files by hand.

## Layout

```
src/
  index.ts               # Re-exports fetcher + graphql + schema
  fetcher.ts             # gqlFetcherFactory — typed fetch wrapper
  schema.ts              # AUTO-GENERATED — all GQL types from schema.gql (DO NOT EDIT)
  graphql/
    index.ts             # AUTO-GENERATED — typed operation objects + GraphQLQuery interface (DO NOT EDIT)
    *.gql                # GQL operation documents (~160 files)
    fragments/           # Shared GQL fragments (imported via #import)
    access-token/        # Access token operations
    admin/               # Admin panel operations
    calendar/            # Calendar integration operations
    license/             # License operations
  __tests__/
    fetcher.spec.ts      # Vitest unit tests for the fetcher

export-gql-plugin.cjs    # graphql-codegen custom plugin — generates graphql/index.ts
codegen.yml              # graphql-codegen config
```

## Code Generation

Two files are generated by running `yarn build` in this package:

| File | Generator | Source |
|---|---|---|
| `src/schema.ts` | `@graphql-codegen/typescript` + `typescript-operations` | `../../backend/server/src/schema.gql` + all `.gql` docs |
| `src/graphql/index.ts` | `export-gql-plugin.cjs` (custom) | same |

```bash
# Regenerate after changing schema.gql or any .gql operation file
yarn build   # runs: gql-gen --errors-only
```

After `prettier --write` runs as a post-file-write hook, both files are committed.

### `export-gql-plugin.cjs`

Custom `graphql-codegen` plugin that produces `src/graphql/index.ts`. For every `.gql` file it:

1. Exports a typed **operation object** (`{ id, op, query, file?, deprecations? }`) using `camelCase` names (e.g. `GetWorkspaceQuery` → `getWorkspaceQuery`).
2. Sets `file: true` on operations that include `Upload` scalar variables (triggers multipart form encoding).
3. Populates `deprecations: string[]` when the operation uses schema-deprecated fields — logged as warnings in canary builds.
4. Resolves `#import "./fragment.gql"` directives and inlines fragment text into the query string.
5. Generates `Queries` and `Mutations` union types that map operation names to their variables and response types.

**Name collision check**: the plugin throws at codegen time if two `.gql` files export the same camelCase name.

## Fetcher

### `gqlFetcherFactory(endpoint, fetcher?)`

Factory that returns a typed `gqlFetch` function bound to a specific endpoint.

```typescript
import { gqlFetcherFactory } from '@affine/graphql';

const gql = gqlFetcherFactory('https://app.affine.pro/graphql');
// or with a custom fetch (e.g. for auth headers, testing)
const gql = gqlFetcherFactory('/graphql', customFetch);
```

### `gql(options)` / `gqlFetch`

```typescript
import { getWorkspaceQuery } from '@affine/graphql';

// Query — variables inferred from the operation type
const data = await gql({
  query: getWorkspaceQuery,
  variables: { id: workspaceId },
});
// data is fully typed as the query's response shape

// Mutation with file upload — automatically uses multipart/form-data
const data = await gql({
  mutation: uploadBlobMutation,
  variables: { workspaceId, blob: file }, // File triggers FormData encoding
});
```

### `RequestOptions<Q>`

| Option | Type | Default | Description |
|---|---|---|---|
| `variables` | inferred | — | Required when the operation has variables; omitted/`undefined` when it has none |
| `context` | `Omit<RequestInit, 'method' \| 'body'>` | — | Passed to `fetch` (e.g. `headers`, `credentials`) |
| `keepNilVariables` | `boolean` | `true` | When `false`, strips `null` and `undefined` from variables before sending |
| `timeout` | `number` | `15000` | Request timeout in ms |
| `signal` | `AbortSignal` | — | Cancellation signal |

### Error handling

- HTTP 4xx/5xx or `errors` in the GQL response → throws `GraphQLError` (from `@affine/error`) with the first error's extensions.
- Non-JSON or unexpected response shape → throws `GraphQLError` with a descriptive message.
- The `x-operation-name` header is always set to the operation name for server-side tracing.

### File upload encoding

When `query.file === true` (set by codegen for `Upload` scalar operations), `formatRequestBody` calls `transformToForm` which builds a `multipart/form-data` body following the [GraphQL multipart spec](https://github.com/jaydenseric/graphql-multipart-request-spec):

```
operations: { query, variables: { ..., file: null }, map: { "0": ["variables.file"] } }
map:        { "0": ["variables.file"] }
0:          <file binary>
```

## Key Types

```typescript
// The shape every operation object conforms to
interface GraphQLQuery {
  id: string;        // camelCase operation name used as the key
  op: string;        // original PascalCase operation name (sent as operationName)
  query: string;     // full GQL query string with inlined fragments
  file?: boolean;    // true if operation involves Upload scalar
  deprecations?: string[]; // deprecation warnings from schema
}

// Union of all query operations (name → variables + response)
type Queries = { name: 'getWorkspaceQuery'; variables: ...; response: ... } | ...

// Union of all mutation operations
type Mutations = { name: 'createWorkspaceMutation'; variables: ...; response: ... } | ...

// Infer variables type from an operation object
type QueryVariables<Q extends GraphQLQuery>

// Infer response type from an operation object
type QueryResponse<Q extends GraphQLQuery>
```

## Adding a New Operation

1. Create a `.gql` file in `src/graphql/` (or a subdirectory).
2. Name the operation in PascalCase — the plugin will camelCase it for export.
3. Use `#import "./fragments/my-fragment.gql"` to reference shared fragments.
4. Run `yarn build` to regenerate `schema.ts` and `graphql/index.ts`.
5. Import the new operation object by its camelCase name from `@affine/graphql`.
