# Обновление компонентов в Storybook

## Изменения

- Обновлены компоненты **Button** и **Menu** в соответствии с [дизайном из Figma](https://www.figma.com/design/vjXvMccMiGELElwpKT4QF2/%D0%A2%D0%B5%D1%81%D1%82%D0%BE%D0%B2%D0%BE%D0%B5-%D0%B7%D0%B0%D0%B4%D0%B0%D0%BD%D0%B8%D0%B5-%D0%B4%D0%BB%D1%8F-Frontend?node-id=1-14998&t=HeDmJcEPdCAMcKrw-0).
- В Storybook отражены новые версии компонентов со всеми доступными состояниями.
- Обновлены пропсы у компонентов **Button** и **Menu**.
- Новые пропсы задокументированы через **TSDoc** и отображаются в разделе документации компонентов в Storybook.

## Пути к компонентам

- `packages/frontend/component/ui/button`
- `packages/frontend/component/ui/menu`

## Запуск проекта

Проект запускается тем же образом, что и в оригинальном репозитории.  
См. инструкцию в файле [`/docs/developing-server.md`](../docs/developing-server.md).

## Запуск Storybook

1. Выполните стандартную процедуру запуска проекта (см. выше).
2. Перейдите в директорию:

   ```bash
   cd packages/frontend/component

   3.	Запустите Storybook командой:
   ```

yarn dev

После этого Storybook будет доступен локально, и можно просматривать все компоненты.

# Примеры в Storybook

    •	Button — представлены все состояния кнопки (основная, вторичная, disabled и т.д.), а также задокументированные пропсы.
    •	Menu — отражает состояния открытия/закрытия, вложенные пункты, а также новые пропсы с описанием через TSDoc.
